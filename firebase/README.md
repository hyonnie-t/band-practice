# Firebase 보안 적용 절차

`database.rules.json`은 2026-10-06 콘솔에 게시했다(효니 확인, "되는 것 같다" 수준 — 불참/참석·시간표 저장과 토큰 없는 요청 거부를 개별로 확인한 기록은 없음). 아래 순서는 규칙을 다시 바꿀 때의 기록이다. 코드(익명 인증)를 먼저 배포하고 나서 규칙을 바꿔야 하고, 순서가 바뀌면 앱이 멈춘다.

## 순서
1. **백업**: `FB_API_KEY=웹API키 node tools/backup.mjs` (Node 18+). 규칙을 바꾸기 전에 `backup/`에 JSON이 생기는지 확인한다. 현재 콘솔 규칙 JSON도 메모장에 복사해둔다(롤백용).
2. **익명 로그인 켜기**: Firebase 콘솔 > Authentication > 시작하기 > 로그인 방법 > 익명 > 사용 설정.
3. **API 키 넣기**: 콘솔 > 프로젝트 설정 > 일반 > 웹 API 키를 `config.js`의 `FB_API_KEY`에 넣고 push. 공개돼도 되는 값이다. 필요하면 Google Cloud 콘솔 > 사용자 인증 정보에서 HTTP 리퍼러를 `hyonnie-t.github.io/*`로 제한한다.
4. **배포 확인**: 개발자도구 Network 탭에서 `firebaseio.com` 요청에 `auth=`가 붙는지, 일정이 평소처럼 뜨는지 본다. 규칙이 아직 열려 있어 인증이 없어도 동작하므로 `auth=` 유무로 확인해야 한다.
5. **규칙 적용**: 콘솔 > Realtime Database > 규칙에 `database.rules.json`을 붙여넣고, 게시 전에 규칙 시뮬레이터로 확인한다.
6. **동작 확인**: 불참/참석 표시, 연습실 시간표(관리자) 변경이 되는지 본다. 막히면 이전 규칙으로 되돌린다.

## 관리자 키 (2026-10-06 추가)
곡·참여자·학사일정·시간표·일정(추가/수정/삭제)을 쓰는 건 관리자만 되게 규칙이 막는다. 관리자 판별 방식:
- 콘솔 데이터 탭에서 최상위에 `adminSecret`(문자열)을 만들고 DB용 관리자 키를 값으로 넣는다(영문·숫자 16자 이상, 코드·레포에는 절대 넣지 않는다). 규칙에서 이 경로는 읽기 금지다.
- 앱 `🔒 관리자`에서 키를 입력하면 `admin/claims/{내 익명 uid}`에 그 값을 쓴다. 규칙이 `adminSecret`과 같을 때만 기록을 허용하고, 그 uid가 관리자가 된다.
- 키를 바꾸려면 `adminSecret`만 바꾸면 되고 기존 관리자 표시는 모두 무효가 된다. 관리자 표시는 익명 계정(uid)에 붙어서, 저장 데이터를 지우거나 계정이 자동 정리되면 키를 다시 입력해야 한다(앱이 알아서 관리자 모드를 풀어준다).
- 키 입력에 횟수 제한이 없으니 짧은 키를 쓰면 안 된다. `adminSecret`이 없으면 아무도 관리자가 될 수 없다(규칙이 `exists()`를 검사한다).
- 예전 `ADMIN_KEY_HASH`(공개 레포의 키 해시)는 없앴다.

## 이번 변경을 적용하는 순서
1. 콘솔 데이터 탭에서 `adminSecret`을 만들고 키를 넣는다.
2. 코드를 main에 올린다(이미 올림). 규칙을 바꾸기 전엔 관리자 로그인이 "키가 맞지 않아"로 거부된다 — 학생 화면은 영향 없다.
3. 규칙 탭에 `database.rules.json`을 붙여넣고 시뮬레이터로 확인한 뒤 게시한다.
   - `/songs` 쓰기, 인증됨(관리자 표시 없음) → 거부
   - `/events/x/absence/가` 쓰기, 인증됨 → 허용
   - `/events/x` 쓰기, 인증됨(관리자 표시 없음) → 거부
4. 앱에서 관리자 키를 입력해 곡·참여자·학사일정·시간표·일정 수정이 되는지, 학생 화면에서 참석/불참 표시가 되는지 본다.
5. 일정 화면에 "곡 목록에 없는 곡의 일정 N개" 배너가 뜨면(삭제된 곡의 일정) 확인 후 삭제한다.

## 규칙 요점
- `members`·`songs`·`schoolCalendar`·`roomSchedule`: 읽기는 토큰이 있으면 되고, 쓰기는 관리자만.
- `events`: 건별(`events/{id}`) 쓰기는 관리자만, 참석/불참(`events/{id}/absence/{이름}`)만 토큰이 있으면 누구나 쓴다.
- `tools/seed-2sem.html`도 관리자 키를 입력해야 쓰기가 된다.

## 한계
앱 코드를 읽는 사람은 익명 토큰을 받을 수 있어서 읽기와 참석/불참 표시는 막지 못한다. 관리자 키가 새면 `adminSecret`을 바꾼다.
